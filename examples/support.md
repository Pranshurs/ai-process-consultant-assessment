# Customer support ticket handling (illustrative example)
1. Customer emails the support inbox with a problem.
2. Support agent reads each email and categorises it as billing, technical or account.
3. Support agent copies the customer details into Zendesk to create a ticket.
4. Technical tickets are forwarded to the engineering team, who often take 2 days to reply.
5. Support agent drafts a reply to the customer using the knowledge base.
6. Refunds over $100 need approval from the support manager before the agent replies.
7. Support agent updates the ticket status in Zendesk and closes it.
